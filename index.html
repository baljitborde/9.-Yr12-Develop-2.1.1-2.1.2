Mission 1: Hunting for Hexadecimal
● ~7 minutes
🔍 Activity 1 — Find hex on your own computer
Your mission
Find your computer's MAC address — the unique hardware address of its network card.
Windows: press Win + R, type cmd, then type ipconfig /all and look for Physical Address.
Mac: System Settings → Network → Wi-Fi → Details → Hardware (or Wi-Fi Address).
Chromebook / no access? Use this example instead: A4-5E-60-C2-19-D7
a) Write down the MAC address you found.
b) How many hex digits does it have? How many bits is that in total? Show how you worked it out.
c) Take the first pair of hex digits. Convert it to binary and to denary. Show your working.
d) Find one more place hex is used on your computer or online (e.g. a Windows error code, a website colour). Write it down and say what it is.
Teacher notes — check your findings
  • A MAC address has 12 hex digits, written as 6 pairs. Each hex digit is 4 bits, so it is 12 × 4 = 48 bits (6 bytes — one byte per pair).
  • Example first pair A4: A = 1010, 4 = 0100, so 1010 0100 = 128 + 32 + 4 = 164. Check: 10 × 16 + 4 = 164 ✓
  • Why hex? Writing 48 bits as 0s and 1s would be very long and easy to mistype. 12 hex digits are short, readable and convert straight back to binary.
  • Other places: Windows error/stop codes (e.g. 0x80070005), colour codes in websites and design apps, memory addresses in error messages, and IPv6 addresses.

Teacher notes — what you were likely to find
  • Broadband: e.g. "150 Mbps" or "500 Mb". This is decimal — megabits per second, 106 bits each second. Note the lower-case b.
  • RAM: e.g. "16 GB". RAM chips are built in powers of 2, so this is really 16 GiB (binary), even though it is usually labelled "GB".
  • Storage: e.g. "256 GB" or "1 TB". Manufacturers use decimal: 1 GB = 109 bytes. That is why less space appears once you use it.
  • File size: Windows shows "KB / MB / GB" but calculates with 1024 (binary). macOS (since 2009) shows sizes in decimal units. So the same file can show a different number on different computers!

✎ Activity 9 — Write your explanation (6 marks)
A customer emails a computer shop with two complaints:
"My new laptop has a 2 TB SSD but Windows says it is only 1.81 TB. And I pay for 100 Mbps broadband, but my downloads never go faster than about 12 MB/s. I think I've been cheated twice!"
Write a reply that explains, with calculations, why the laptop and the broadband are both working as they should.
Mark scheme — tick each point you made (1 mark each, max 6)
The SSD maker uses decimal prefixes: 2 TB = 2 × 1012 bytes.
Windows measures in binary units (1024s), even though it writes "TB": 1 TiB = 240 bytes.
Calculation: 2 × 1012 ÷ 240 ≈ 1.82, which Windows shows as 1.81 — the same amount of space.
Broadband is sold in megabits per second (lower-case b), but downloads are shown in megabytes per second (capital B).
Calculation: 100 Mbps ÷ 8 = 12.5 MB/s, so about 12 MB/s is the full speed.
Extra detail: some capacity is also used by network overheads / the operating system, so slightly lower figures are normal.
Clear conclusion that neither product is faulty and the customer has not been cheated.
Your score: 0 / 6
Model answer

Thank you for your email. Neither your laptop nor your broadband is faulty — the difference comes from how the numbers are measured. SSD makers use decimal prefixes, so your 2 TB drive holds 2 × 1012 bytes. Windows measures storage in binary units, where one "TB" is really a tebibyte of 240 bytes. 2 × 1012 ÷ 240 is about 1.82, which Windows displays as 1.81 TB, so all of the space is there. Your broadband speed is given in megabits per second, but downloads are shown in megabytes per second, and there are 8 bits in a byte. 100 Mbps ÷ 8 = 12.5 MB/s, and a little of that is used by the network itself, so about 12 MB/s means you are getting the full speed you pay for.
